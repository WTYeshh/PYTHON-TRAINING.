# 6D Python Training

This workspace contains practice from a seven-day training class, including Python basics, web development, and a Django survey project.

## Topics Covered

- **Python basics:** variables, data types, operators, input, and output
- **Control flow:** conditions, loops, and comparisons
- **Strings and collections:** string methods, slicing, and lists
- **Functions:** reusable code, parameters, and return values
- **Object-oriented Python:** classes, objects, attributes, and methods
- **Web basics:** HTML structure, CSS styling, and JavaScript DOM updates
- **Django:** apps, models, forms, views, templates, URLs, migrations, and authentication

## Project Structure

- `day-1/` - Python practice and frontend examples
- `SurveyProject/SurveyProject/` - Django survey application

## Run Python Examples

```powershell
python day-1\control_flow.py
python day-1\string_slice.py
python day-1\oop_college.py
```

## Run the Django Survey

```powershell
cd SurveyProject\SurveyProject
python manage.py migrate
python manage.py runserver
```
